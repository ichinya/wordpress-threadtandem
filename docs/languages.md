# Языки интерфейса

В плагин включены две полные языковые версии: русский (`ru_RU`) и английский (`en_US`). Обе содержат все актуальные строки интерфейса, сообщений и подписей. Для PHP используются файлы PO/MO, для редактора записей — JSON. Отдельно скачивать перевод не требуется.

Язык выбирается стандартными настройками WordPress:

- **Пользователи → Профиль → Язык** — язык интерфейса конкретного администратора.
- Если в профиле выбран **Язык сайта**, используется **Настройки → Общие → Язык сайта**.

Настройки ThreadTandem, синхронизация, массовая отправка, подтверждения и панель редактора следуют одному выбранному языку. Отдельного переключателя языка внутри плагина нет.

Если WordPress уже скачал более старый языковой пакет, его готовые переводы сохраняют приоритет, а недостающие новые строки берутся из каталога, включённого в плагин.

Стандартная подпись ссылки в Telegram зависит от языка сайта: «Читать статью» для русского и «Read the article» для английского. Язык профиля администратора на неё не влияет. Оставьте поле **Текст ссылки на статью** пустым, чтобы использовать стандартную подпись. Свой текст сохраняется без перевода и не меняется при переключении языка.

Каталоги находятся в `languages/`. Правила обновления и проверки описаны в `docs/wordpress-org.md`. Изменение переводов само по себе не является командой изменить версию или опубликовать релиз.
